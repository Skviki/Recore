# Recor

Recor is a simple screen recording program with a straightforward interface.

Just press the button and the recording starts. Once you finish recording, the video is automatically saved to your **Videos** folder.

The main goal of Recor is to make it **quick and easy to capture something**.

I originally created this program for myself. I needed to record a video, but other programs I tried would sometimes produce glitches or other unwanted side effects. Recor has a relatively small set of features, but the features it does have are designed to work reliably.

Recor also supports **screenshots**, so you do not need to install a separate program just for taking screenshots.

## Important

This project was originally created for my own use, so I cannot guarantee that it will work correctly on every system.

I am also still a beginner software developer, and Recor is one of my personal projects.
